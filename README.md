# Resources for the T5 Podcast
Teaching is hard work.  As educators, we feel a tension between what we feel like we should be doing and what we are doing in the classroom.  T5: Talking Through Teaching Tensions Together, brings together faculty from across academia to discuss how they navigate these challenges at the post-secondary level. This serves as a repository for the additional resources shared by guests of the podcast.
