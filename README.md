# Resources for the T5 Podcast
<img align="left" width="100" height="100" src="/T5logo.png" alt="T5 Logo, Microphone with speech bubble containing letter T and number 5."> Teaching is hard work.  As educators, we feel a tension between what we feel like we should be doing and what we are doing in the classroom.  T5: Talking Through Teaching Tensions Together, brings together faculty from across academia to discuss how they navigate these challenges at the post-secondary level. This serves as a repository for the additional resources shared by guests of the podcast.
